# 🎨 Blender GitHub Render (20x Parallel Cloud Farm)

Render your Blender animations across 20 simultaneous GitHub Actions cloud runners for free, and automatically upload the finished video directly to your **Google Drive**!

## Folder Structure

Store all your Blender project files inside the **`Blender Project/`** folder:

```
├── Blender Project/
│   ├── Lion.blend
│   ├── Drift.blend
│   └── your_project.blend
├── .github/workflows/
│   └── render-parallel.yml
├── render_chunk.py
├── setup_blender.py
├── assemble_video.py
├── upload_to_gdrive.py
├── setup_gdrive_auth.py
└── summarize_video.py
```

## ☁️ Automatic Google Drive Upload Setup (One-time, 2 minutes)

Instead of manually downloading large zip files from GitHub, have your rendered MP4 video uploaded straight to your **Google Drive** and get a direct playable link!

### Step 1: Create a free Google Cloud App
1. Go to the [Google Cloud Console](https://console.cloud.google.com/) (100% free).
2. Click **Select a project** (or **New Project**) → Name it **Blender Farm** → Click **Create**.
3. In the search bar at top, search for **Google Drive API** and click **Enable**.
4. Go to **APIs & Services** → **OAuth consent screen**:
   - Select **External** → Click **Create**.
   - Enter **App name**: `Blender Farm` and your email.
   - Click **Save and Continue** until finished.
5. Go to **APIs & Services** → **Credentials**:
   - Click **+ Create Credentials** → **OAuth client ID**.
   - Application type: **Web application** (or **Desktop app**).
   - Under *Authorized redirect URIs*, click **+ Add URI** and enter:
     `http://localhost:8085/`
   - Click **Create**. Download the JSON or copy the **Client ID** and **Client Secret**.

### Step 2: Authorize from your computer
Run the interactive setup helper in your terminal:
```bash
python3 setup_gdrive_auth.py
```
* Enter your Client ID and Client Secret (or drag the downloaded JSON file).
* Your web browser will open asking you to sign into Google and click **Allow**.
* The terminal will immediately display a ready-to-use secret string for GitHub!

### Step 3: Add to GitHub Secrets
1. Go to your repository on GitHub:
   `https://github.com/lorem5176/Blender-github-render`
2. Click **Settings** ⚙️ → **Secrets and variables** → **Actions**.
3. Click **New repository secret**:
   - **Name:** `GDRIVE_CREDENTIALS`
   - **Value:** Paste the JSON string generated by the script.
4. Click **Add secret**.

🎉 **You're all set!** Every render workflow will now automatically upload your final video to your Google Drive and give you a direct viewable link!

## How to Render

1. **Add your `.blend` file:**
   Save or copy your `.blend` file into the `Blender Project/` folder.
   Push to GitHub:
   ```bash
   git add "Blender Project/"
   git commit -m "Add project"
   git push
   ```

2. **Start the Render on GitHub:**
   - Go to your repository on GitHub → **Actions** tab.
   - Click **Blender Parallel Render (20x Speed)** on the left.
   - Click **Run workflow**:
     - **`blend_file`**: Enter the filename (e.g. `Lion.blend`, `Drift.blend`) or leave as **`AUTO`** to automatically render the project in your folder!
     - **`render_engine`**: `CYCLES` (default for maximum quality).
   - Click **Run workflow**.

3. **Check Specifications & Watch on Google Drive:**
   When the run completes, GitHub displays the **Video Information Card**:
   - 📐 **Resolution** (e.g. 1920×1080)
   - ⏱️ **Duration** (e.g. 12 sec, 1 min 30 sec)
   - 🎞️ **Frame Rate** (e.g. 24 fps)
   - 💾 **File Size** (e.g. 14 MB)
   - ☁️ **Google Drive Link** (direct link to watch/download your video!)
   - You can also download the `.mp4` file and raw frames zip under the **Artifacts** section!
